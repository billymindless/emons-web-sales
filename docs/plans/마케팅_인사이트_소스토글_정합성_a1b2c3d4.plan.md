# 마케팅 인사이트 — 분석 소스 토글 + 헤더/라인 정합성 리포트

## Overview

현장 입력(`app_orders.category` + `total_amount`)과 임포트 라인(`app_order_items` + taxonomy)을
같은 차트에 섞지 않도록 **분석 소스를 명시 선택**하고, 헤더 금액·원가와 라인 합의
차이를 **정합성 리포트**로 분리 표시한다.

## Goals

1. 마케팅 인사이트(테넌트·슈퍼어드민)에 분석 소스 토글 추가
2. 소스별 집계 규칙 고정 (이중집계 방지)
3. 헤더 vs 라인 금액/원가 차이 리포트 추가
4. DB 스키마 변경 없음 (기존 컬럼·헬퍼 재사용)

## Analysis source toggle

UI (분석 시작 버튼 직후, 결과 상단):

| 값 | 라벨 | 용도 |
|----|------|------|
| `header` (기본) | 현장 주문 헤더 | 판매자 입력 category + total_amount |
| `line` | 원장 라인 + 대분류 | app_order_items → taxonomy 대분류 |

규칙:

- **금액 KPI·구매이유·지도·방문경로:** 항상 주문 헤더 `total_amount` (판매 진실)
- **카테고리 인기(③) / 다면분석 품목 차원:**
  - `header` → `orders.category` explode, **건수** (기존)
  - `line` → items + `_cached_taxonomy_map`, 카테고리별 **주문 수(distinct order_id)** (금액 분배 안 함)
- **③-2 라인 품명 / 다면분석 품목명·대분류:** 기존 라인 경로 유지 (소스와 무관하게 사용 가능)
- 배너로 현재 소스·규칙을 한 줄 안내

session_state 키: `{key_prefix}_analysis_source` (`mi_tenant` / `mi_superadmin`).

## Header vs line discrepancy report

분석 적용 기간(A∪B 또는 A+B 유니온) 주문에 대해:

입력: orders `id, total_amount, cost_price, import_source, category, order_date`  
+ `load_order_items_batched(..., "order_id, line_cost, line_total, product_name")`

출력 컬럼:

- 주문ID, 주문일, import_source, 헤더매출, 라인매출합(line_total), 매출차이
- 헤더원가(cost_price), 라인원가합(line_cost), 원가차이
- 라인수, 헤더카테고리

필터/요약:

- 메트릭: 라인 있는 주문 수, |매출차이|>0 건, |원가차이|>0 건, 차이 합계
- 기본 필터: 라인 있음 AND (매출차이≠0 OR 원가차이≠0); "전체(라인 없는 주문 포함)" 체크 옵션
- dataframe + CSV 다운로드

위치: 다중기간 비교와 다면분석 **사이** expander `헤더 ↔ 라인 정합성`.

## Verification

1. header 소스: 기존 ③ 카테고리 건수와 동일 계열
2. line 소스: 라인 없는 기간은 "데이터 없음"/0, taxonomy 미분류는 `(미분류)`
3. 정합성: 라인 1건·헤더와 동일한 cost면 차이 0; attach만 된 주문은 원가차이 가능
4. 분석 시작 전 토글·리포트 미표시
5. ast.parse + 커밋/푸시
