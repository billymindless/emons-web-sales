# ERP 근태/휴가 관리 모듈 플랜 (v5 최종)

## 기존 구조 검증 결과

- 모든 거래 데이터는 `db_filename`(매장) 단위로 완전 분리
- 직원은 표시명 문자열로만 기록 (`app_users.id` FK 없음)
- 근태 모듈: `home_db_filename + employee_name` 조합이 직원 식별자

---

## 전체 기능 개요

```
사전 계획 레이어        실제 기록 레이어
─────────────────       ─────────────────
최소 인원 규칙 설정      근태 입력 (실제 출퇴근)
      ↓                       ↓
근무 일정 계획           캘린더 (계획 + 실제 오버레이)
(저장 시 규칙 검증)       (미달 날짜 빨간 경고)
      ↓
시차·추가근무 관리  →  월말 급여 요약
연차/월차 관리     →  엑셀 다운로드
```

---

## 확정된 설계 사항

### 반차 0.5일
`leave_deduction`: 연차=1.0, 반차=0.5, 기타=0
`잔여 연차 = annual_days - SUM(leave_deduction)`

### 월차 자동 적립
`hire_date` 기준: `월차 적립 = min(경과 개월, 11)일`

### 시차(보상시간) 잔액
`work_type`: `시차적립`(+분) / `시차사용`(-분)
자동 승인: 잔여 ≥ 신청 분수이면 즉시 approved

### 최소 근무 인원 검증
근무 일정 저장 시: 해당 날짜의 요일 규칙 확인 →
모든 시간대에서 배정 인원 ≥ min_staff이어야 저장 가능
미달 시: 구체적 경고 메시지 표시 (예: "14:00~18:00 구간 1명 부족")

## DB 설계 (Supabase 신규 테이블 5개)

### 1. `app_staffing_rules` - 요일별 시간대 최소 근무 인원 규칙

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | BIGSERIAL PK | |
| db_filename | TEXT NOT NULL | 매장 |
| day_of_week | INT NOT NULL | 0=월 / 1=화 / … / 5=토 / 6=일 |
| slot_start | TIME NOT NULL | 시간대 시작 (예: 09:00) |
| slot_end | TIME NOT NULL | 시간대 종료 (예: 13:00) |
| min_staff | INT NOT NULL DEFAULT 1 | 최소 근무 인원 |
| created_by | TEXT | |
| updated_at | TIMESTAMPTZ DEFAULT now() | |

요일별 설정 예:
```
평일(월~금): 09:00~13:00 최소 2명 / 13:00~18:00 최소 2명
주말(토·일): 10:00~15:00 최소 1명
```

### 2. `app_shift_schedules` - 사전 근무 일정 계획

**저장 시 검증 로직:**
```python

rules = query app_staffing_rules WHERE db_filename AND day_of_week = shift_date.weekday()

# 각 규칙(시간대)별로 배정 인원 카운트
for rule in rules:
    count = len([s for s in all_shifts_on_date
                 if s.shift_start < rule.slot_end
                 and s.shift_end > rule.slot_start])
    if count < rule.min_staff:
        → 저장 차단 + 경고: f"{rule.slot_start}~{rule.slot_end} 구간 {rule.min_staff - count}명 부족"
```

## 화면별 상세 명세

### 탭 1 - 근무 일정 계획 (store_admin 전용)

**주/월 단위 일정 그리드:**
- 날짜 범위 선택 (1주 또는 1개월)
- 직원별 행 × 날짜별 열 그리드
- 각 셀: 출근~퇴근 시각 입력 (또는 비워두면 휴무)
- 근무 장소 입력 (타 매장·행사장 등)

**저장 버튼 클릭 시:**
```
각 날짜별로 staffing_rules 검증
→ 통과: app_shift_schedules INSERT
→ 실패: 미달 시간대 명시 경고 (저장 차단)
   예: "5월 26일(화) 13:00~18:00 구간 1명 부족
        현재 배정: 김철수, 이영희 (2명 필요)"
```

### 탭 2 - 최소 근무 인원 규칙 설정 (store_admin 전용)

- 요일 탭 (월/화/수/목/금/토/일)
- 각 요일별 시간대 목록: 시작시각 / 종료시각 / 최소인원
- [규칙 추가] / [삭제] 버튼
- 저장 시 `app_staffing_rules` UPSERT

### 탭 3 - 월별 캘린더

- 날짜 셀: **계획(회색)** + **실제 근태(색상 배지)** 오버레이
- 최소 인원 미달 날짜: 셀 테두리 빨간색 + "인원 부족" 경고 텍스트
- 배지 색상: 연차(초록) / 반차(하늘) / 조퇴·지각(빨강) / 시차적립(주황) / 시차사용(파랑) / 행사(보라)
- `work_location_name` 있으면 소자로 장소명 표기

### 탭 4 - 근태 입력 (실제 출퇴근 기록)

- 날짜 / work_type / 출·퇴근 시각 / 근무 장소 / 비고
- `leave_deduction` 자동 설정
- user: 본인 고정 / 관리자: 직원 선택

### 탭 5 - 추가근무 & 시차 관리

**관리자 - 주말 회의 일괄 등록:**
```
날짜 + 적립 분수(매번 직접 입력) + 참석 직원 체크박스
→ 일괄 INSERT (시차적립)
```

**직원 - 시차 사용 신청:**
```
잔여 시차: X분 표시
신청 분수 입력
→ 잔여 ≥ 신청: 자동 approved
→ 잔여 < 신청: pending + 관리자 알림
```

**직원 - 추가근무 신청 / 관리자 - 승인 목록**

### 탭 6 - 연차/월차 관리 (관리자 전용)

관리자 입력: 직원 선택 → 입사일 + 해당 연도 annual_days → 저장

직원별 현황 테이블:

| 직원명 | 입사일 | 연차부여 | 연차사용 | 잔여연차 | 월차적립 | 월차사용 | 잔여월차 | 잔여시차(분) |
|--------|--------|--------|--------|--------|--------|--------|--------|------------|

### 탭 7 - 월말 급여 요약 (관리자 전용)

| 직원명 | 소속매장 | 정상근무일 | 연차 | 반차 | 조퇴/지각(분) | 시차사용(분) | 추가근무(분) | 잔여연차 | 잔여시차(분) |
|--------|---------|---------|-----|-----|------------|------------|------------|--------|------------|

- `st.dataframe` + 엑셀 다운로드

### superadmin - 통합 캘린더 & 매장별 현황

- 매장 필터 + 월 선택
- 달력 그리드: 직원명 + 배지를 매장 구분 색으로 표시
- 최소 인원 미달 날짜: 매장명과 함께 빨간 경고
- 하단 테이블: 직원명 / 소속매장 / 근무일수 / 연차 / 시차잔여 / 추가근무(분)
